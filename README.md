# Sin Registro
Puzzle narrativo 2D en Godot 4.7 (Forward+). PC, teclado y mouse.

## Cómo correrlo
1. Clonar el repositorio.
2. Abrir `project.godot` con Godot 4.7.
3. F5 (escena principal: la intro).

## Controles
- Moverse: WASD o flechas
- Interactuar / avanzar diálogo: F o Espacio
- Inventario: E (click en un objeto, y click en otro para combinar)
